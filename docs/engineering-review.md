# 다운로드 확장 MVP 엔지니어링 검토

작성 일시: 2026-09-10 13:40:26 KST
검토 대상: 기존 대화의 구현 제안 및 [최종 개발 계획](../dev-plan/implement_20260910_134026.md)
검토 방식: 아키텍처·계약·실패 경로·테스트·설치/롤백 체크리스트에 따른 설계 검토. 독립 외부 전문가나 별도 에이전트 검토를 수행한 것은 아니다.

## 1. 판정
**ready — 아래 필수 수정 사항을 최종 계획에 반영하여 구현 착수 가능.** 현재 저장소는 초기 상태다. 구현·빌드·다운로드 성공은 아직 검증하지 않았다.

목표는 macOS에서 확장에 URL을 입력해 실제 미디어를 저장하고 파일의 유효성까지 검사하는 개발용 MVP다. 공개 웹 스토어 배포와 모든 사이트 지원은 범위에 포함하지 않는다.

## 3. 아키텍처·계약 검토
- 단일 호스트, 단일 다운로드 실행, 최대 20개 대기열로 MVP 복잡도를 제한한다. 서버·Redis·별도 상주 데몬은 필요하지 않다.
- 화면, 메시지 중계, 작업 상태, 다운로드 프로세스의 책임을 분리한다. DB를 UI와 호스트가 함께 수정하지 않는다.
- Native 메시지 길이/버전, requestId, jobId, seq, 오류 코드와 상태 전이를 계약으로 명시한다.
- Chrome 종료 후 계속 실행은 제외한다. 패널 종료와 브라우저 종료의 동작 차이를 문서와 테스트에 반영한다.
- 최고 화질 결과를 무조건 MP4로 표시하지 않는다. 실제 컨테이너와 화질을 표시한다.
- Native Host의 다중 기동은 단일 인스턴스 잠금과 명시적 충돌 오류로 처리한다. 멀티 프로필 동시 다운로드는 구현 범위 밖이다.

## 4. 테스트 커버리지 검토
- 정상 경로: 직접 파일, 영상/음성 분리 병합, MP3 변환, 실제 확장 입력부터 저장까지.
- 실패 경로: 잘못된 URL, HTTP 실패, 누락 의존성, 쓰기 권한, 디스크 부족, 손상 파일, 시간 초과.
- 수명 경로: 취소/완료 경합, 중복 요청, 패널 종료, 호스트 종료, 재시도, 복구.
- 설치 경로: 신규·반복·실패·제거·롤백, 공백/한글 경로, GUI Chrome의 PATH 차이.
- 증거: 테스트 보고서·미디어 정보·디코딩 결과·브라우저/엔진 버전·화면 캡처. 외부 다운로드 실패를 로컬 fixture 성공으로 대체하지 않는다.
- 테스트 미실행은 skip/blocked로 기록한다. 계획 문서 검사는 제품 기능 테스트가 아니다.
