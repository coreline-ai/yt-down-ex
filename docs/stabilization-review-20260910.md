# 안정화 검토 — 2026-09-10

검토 범위: Chrome 확장 UI, Native Messaging, SQLite 작업 큐, yt-dlp/FFmpeg 실행·취소·결과 검증, 설치·롤백. 저장소 코드 검토와 자동 테스트에 의한 자체 검토이며 독립 외부 감사가 아니다.

## 검토한 기존 보호 동작

- URL·옵션·저장 경로 검증, shell 없이 subprocess 인자 전달, 출력 이름 정규화 및 덮어쓰기 방지.
- 작업별 임시 폴더, ffprobe 스트림·길이 확인 후 완료 처리.
- 단일 호스트 잠금, 최대 20개 대기열, requestId 중복 방지, 종료 상태의 뒤늦은 이벤트 차단.
- 취소 시 프로세스 그룹 종료, 호스트 EOF/강제 종료 후 중단 상태 복구.
- 완료·실패 등 종료 기록만 삭제. 작업 정리 중에는 삭제를 거부해 실행 중인 worker의 기록 유실 방지.
- 오프라인 wheel 설치, 설치 실패 시 기존 릴리스 유지, 롤백, 제거 시 다운로드 파일 보존.

## 남는 제한과 후속 안정화

- 외부 사이트의 403·로그인 요구·서버 권한은 앱 성공 보장 대상이 아니다. W3 MP4는 앞선 실제 사용자 Chrome에서 성공했지만 모든 사이트 지원을 뜻하지 않는다. Google 샘플은 익명 읽기 권한이 거부된 주소다.
- 자동 테스트는 로컬 fixture와 임시 브라우저 프로필을 사용한다. 장시간·수천 건 기록·대용량 영상·실제 디스크 전체 소진·SQLite 손상은 이번 자동 검사로 포괄 검증하지 않는다.
- 수천 건 기록에서는 시작 시 전체 기록을 읽는 구조의 메모리·시작 시간 측정이 필요하다. DB 자체 쓰기 장애에서 worker 복구를 강화하는 후속 작업도 권장한다.
- Chrome 완전 종료 후 지속 다운로드 및 이어받기 미지원. YouTube 실제 다운로드는 이번 안정화 범위에서 검증하지 않았다.

## 추가 기능 제안 — 아직 구현하지 않음

1. **MP4 호환 저장 옵션**: 원본 유지 / MP4(H.264+AAC)를 명시적으로 선택. 변환 시간·진행 상태와 최종 코덱 표시. 사용자가 재생 가능한 영상 결과를 쉽게 확인하도록 우선 구현 권장.
2. **다운로드 전 미리보기**: 제목·길이·실제 화질·영상/음성 유무·예상 용량을 분석 결과로 표시. 확인되지 않은 값은 미확인으로 표시.
3. **기록 관리**: 실패 필터, 검색, 여러 항목 선택 삭제, 실패 기록 일괄 삭제. 파일 삭제는 별도 기능으로 구분.
4. **일시적 오류 재시도**: 연결 끊김·일시적 서버 오류만 횟수 제한 및 지연 후 재시도. 403/404는 무한 재시도하지 않음. 재시도 이력 표시.
5. **설치·업데이트 안내 개선**: 확장과 호스트 버전 표시, 호환성 진단, 사용자 실행형 업데이트·롤백 안내.

우선순위 제안: MP4 호환 저장 → 분석 미리보기 → 기록 관리. 이어받기·예약·브라우저 종료 후 실행은 엔진 수명과 상태 저장 설계 변경이 필요하므로 별도 단계로 진행.
